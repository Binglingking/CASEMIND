# 230021 素材归因及报表 测试用例（XMind）

## 一、前置条件验证
- ### 1.1 账号授权
  - 未授权渠道账号时，报表无法拉取该渠道数据，验证是否有对应提示
  - 已授权账号被删除后，数据是否不再纳入统计
  - 授权多个渠道账号，验证各渠道数据独立拉取，不互串
- ### 1.2 素材归档
  - 未上传至投平台的素材，报表中不展示
  - 已上传但被删除状态的素材，不纳入报表统计
  - 上传素材后 MD5 是否成功生成并与渠道素材 MD5 匹配

---

## 二、素材归因逻辑
- ### 2.1 MD5 映射关联
  - #### 2.1.1 渠道素材 → 平台素材 MD5 匹配
    - 渠道素材 MD5 与平台素材 MD5 完全一致，验证是否成功建立映射
    - 渠道素材 MD5 与平台无匹配项，验证报表中该素材不展示或显示"-"
    - 同一素材裁剪为多个尺寸上传到同一文件夹，验证所有尺寸均映射到同一文件夹 ID
  - #### 2.1.2 数据拉取频率
    - 上线前全量拉取：验证历史所有已授权账号的素材数据均拉取
    - 每天上午9点拉取前一天数据：验证定时任务触发时间准确
    - 数据更新频率：每小时更新上一个整点数据，验证各整点数据更新是否准时
  - #### 2.1.3 前后端数据打通
    - 前端数据（曝光/点击/互动）与后端数据（注册/购买/付费）通过素材 MD5 + 创意 ID 关联，验证数据匹配正确性
    - 百度搜索 PC 端：验证从渠道后台拉取转化数据（不走 UData）
    - 其他渠道（B站/巨量/腾讯3.0/微博）：验证后端数据统一来源于 UData
- ### 2.2 素材聚合逻辑
  - #### 2.2.1 素材文件夹维度聚合
    - 文件夹下有 2 个素材，各自曝光数之和 = 文件夹总曝光，验证加法正确
    - 文件夹下素材为空，报表中该文件夹数据指标显示 0 或"-"
    - 同一素材被归属到不同文件夹（不应存在），验证系统处理逻辑
  - #### 2.2.2 设计师/创意人维度聚合
    - 素材文件夹绑定设计师后，验证该文件夹下所有素材的指标数据均汇总到对应设计师
    - 一个文件夹绑定多个设计师，验证数据是否按人拆分或合并（需明确需求）
    - 文件夹未绑定设计师/创意人，设计师维度报表中该文件夹数据不展示

## 三、筛选区

- ### 3.1 日期选择器
  - #### 3.1.1 快捷时间范围
    - 验证所有已有快捷项（今天/昨天/过去7天等）可正常选择
    - 新增"过去14天"选项：不含当日，起始 = S-14，结束 = S-1，验证边界日期正确
    - 默认打开页面日期为"过去14天"，验证初始加载状态
  - #### 3.1.2 自定义日期范围
    - 选择跨度 = 60 天（最大限制），验证可正常查询
    - 选择跨度 = 61 天，验证系统提示不可超过60天，且无法查询
    - 选择跨度 = 1 天（最小范围），验证可正常查询
    - 起始日期 > 结束日期，验证系统拦截并提示
    - 选择未来日期，验证是否允许或提示
  - #### 3.1.3 与时间粒度的交互
    - 切换粒度后（如从"按日"→"按双周"），日期选择器已选范围不重置，验证原范围保留

- ### 3.2 数据维度选择
  - 默认选中"素材文件夹"，验证初始状态
  - 切换为"设计师"，报表列变更：隐藏素材文件夹 ID、素材预览、素材类型、素材标签
  - 切换为"创意人"，报表列变更同设计师规则
  - 维度选择为单选，不可多选，验证 UI 交互
  - 切换维度后数据自动刷新，不需要额外点击"查询"

- ### 3.3 时间粒度
  - #### 3.3.1 前置条件：需先输入筛选条件
    - 筛选条件为空时点击切换粒度，验证系统弹出提示："请输入筛选条件"
    - 切换粒度按钮 hover 显示 tooltip："请先设置筛选条件，再切换时间粒度"
    - 已输入筛选条件后，粒度切换按钮可正常操作
  - #### 3.3.2 合计（默认）
    - 每个分析主体仅输出 1 行聚合数据，验证行数
    - 报表数据详情列不展示"时间"列，验证列渲染
    - 合计时默认排序：按"花费"降序，验证初始排列顺序
  - #### 3.3.3 按日
    - 选择 N 天日期区间，报表输出 N 行（每天1行），验证行数与日期匹配
    - 时间列格式：年/月/日，如 2025/11/25，验证格式
    - 按日默认排序：按"时间"降序，验证初始排列顺序
  - #### 3.3.4 按双周
    - 选择日期区间"2025/11/01-2025/11/20"：
      - 第一双周：2025/11/01-2025/11/14（完整14天），验证时间列显示
      - 第二双周：2025/11/15-2025/11/20（不足14天，截断），验证显示格式正确
    - 选择恰好 14 天区间，输出 1 行，验证单双周处理
    - 选择 28 天区间，输出 2 行，验证整双周场景
    - 选择 29 天区间，输出 3 行（第3行不足14天），验证尾部截断
    - 时间列格式：起始年/月/日-结束年/月/日，如 2025/11/12-2025/11/25，验证格式
    - "?" tooltip 提示文案："起始日期为起点，每14天为一个滚动双周；结束日期不满14天，则为不完整双周"，验证文案
    - 按双周默认排序：按"时间"降序，验证初始排列顺序

- ### 3.4 精准筛选
  - #### 3.4.1 素材文件夹 ID
    - 输入单个 ID，验证精准匹配返回
    - 输入多个 ID（逗号分隔），验证所有 ID 对应数据均返回
    - 输入不存在的 ID，验证返回空或提示无数据
    - 输入含空格的 ID 字符串，验证是否做 trim 处理
    - 输入非法字符（如特殊符号），验证字段校验
  - #### 3.4.2 素材文件名
    - 输入完整文件名，验证精准匹配
    - 输入部分关键词（模糊搜索），验证包含该关键词的文件名均返回
    - 输入不存在的文件名，验证返回空
    - 输入特殊字符，验证模糊搜索安全性（防 XSS/SQL 注入）
  - #### 3.4.3 素材类型
    - 下拉单选：选"视频"，验证报表只展示视频类素材
    - 下拉单选：选"图片"，验证报表只展示图片类素材
    - 验证下拉选项只有"视频"和"图片"两项
    - 不选择（默认），验证返回全部类型
  - #### 3.4.4 素材标签
    - 下拉级联多选，数据来源为素材中心-标签管理，验证数据同步
    - 选择一级标签，验证返回该标签下所有素材
    - 选择二级标签，验证精准返回对应素材
    - 多选不同标签，验证取并集返回
    - 标签管理中新增标签，筛选项是否同步更新
  - #### 3.4.5 创意人
    - 下拉多选，数据来源素材中心已写入的创意人，验证数据同步
    - 选择一个创意人，验证只返回该创意人关联的数据
    - 多选创意人，验证取并集
    - 已删除的创意人，是否还出现在下拉列表中
  - #### 3.4.6 设计师
    - 规则同创意人，验证单选/多选/删除场景
  - #### 3.4.7 多条件组合筛选
    - 同时设置日期 + 素材类型 + 设计师，验证结果为交集
    - 全部条件均填写，验证查询正确
    - 清空所有筛选条件，验证报表恢复默认

## 四、报表区展示

- ### 4.1 属性指标列渲染（按维度控制）
  - #### 4.1.1 时间列
    - 时间粒度=合计：时间列不展示，验证列隐藏
    - 时间粒度=按日：显示"年/月/日"格式，如 2025/11/25
    - 时间粒度=按双周：显示"起始年/月/日-结束年/月/日"，如 2025/11/12-2025/11/25
    - 三种维度（素材文件夹/创意人/设计师）均显示时间列（合计除外）
  - #### 4.1.2 素材文件夹 ID & 文件夹名称
    - 素材文件夹维度：ID 和名称在同一单元格中展示
    - 鼠标 hover 在表格行时，ID 旁出现"复制"图标
    - 点击"复制"图标，验证 ID 成功复制到剪贴板
    - 设计师/创意人维度：该列隐藏
  - #### 4.1.3 素材预览
    - 素材文件夹维度：随机展示文件夹中任意一张图片
    - 图片类素材：点击缩略图可放大预览
    - 视频类素材：支持播放预览（根据评论需求），验证播放功能
    - 文件夹内无素材时，预览列显示占位符或"-"
    - 设计师/创意人维度：素材预览列隐藏
  - #### 4.1.4 素材类型
    - 展示素材文件夹的类型（视频/图片）
    - 设计师/创意人维度：该列隐藏
  - #### 4.1.5 素材标签
    - 展示文件夹绑定的标签，多个标签完整展示
    - 设计师/创意人维度：该列隐藏
  - #### 4.1.6 创意人（列）
    - 素材文件夹维度：展示文件夹所属创意人
    - 创意人维度：展示创意人姓名
    - 设计师维度：该列隐藏

- ### 4.2 数据指标
  - #### 4.2.1 IPI 指标
    - 计算公式：曝光数 / 安装数，验证计算结果正确
    - 安装数为 0 时，IPI 显示"-"或"∞"，验证除零处理
    - IPI 与其他指标（曝光、安装数）数据联动一致
  - #### 4.2.2 默认勾选指标
    - 默认展示列：花费、返点后花费、展示、点击、点击率、安装数、安装转化率、累计充值、累计充值人数、IPI
    - 验证默认列数量及顺序正确

## 五、报表操作

- ### 5.1 渠道投放详情弹窗
  - 点击"素材文件夹名称"，弹窗正常打开
  - 弹窗内数据按筛选条件过滤（时间、维度等）
  - 弹窗内展示该文件夹在各渠道的数据，每渠道一行
  - 属性指标：包含"渠道"列
  - 数据指标跟随素材文件夹报表已选指标
  - 弹窗关闭后，主报表状态不变
  - 多次点击不同文件夹名称，弹窗内容正确切换

- ### 5.2 数据明细提示
  - 提示内容包含【数据来源提示】和【更新频率】两段文案
  - 数据来源提示：百度搜索 PC 端标注"从渠道后台拉取"，其他渠道标注"来自 UData"
  - 更新频率提示文案："每天上午9点进行数据拉取与更新，每小时更新上一个整点的数据"

- ### 5.3 表格行高设置
  - 默认行高：初次进入页面行高为"默认行高"
  - 切换为"宽松行高"，表格行高变宽，视觉验证
  - 刷新页面后，行高设置保持上次选择（本地记忆）
  - 换浏览器/换用户，行高是否独立存储

- ### 5.4 表格宽度自定义
  - 拖动列边界可调整列宽
  - 拖拽后宽度记忆（刷新页面保持）
  - 最小列宽限制：拖到极限后不可继续缩小
  - 多列均可独立拖拽

- ### 5.5 报表固定列
  - 默认固定前三列，横向滚动时前三列不随之滚动
  - 不同维度下固定列内容正确：
    - 素材文件夹-按日：日期、素材文件夹、素材预览
    - 其他维度验证前三列分别是哪些

- ### 5.6 自定义展示指标
  - 点击自定义列按钮，弹出配置面板
  - 属性指标：日期、素材文件夹、素材预览、素材类型、素材标签、创意人、设计师（按维度控制显隐）
  - 数据指标：覆盖投放概览所有指标，支持勾选/反选
  - 默认勾选项：花费、返点后花费、展示、点击、点击率、安装数、安装转化率、累计充值、累计充值人数、IPI
  - 保存模板：只保存数据指标（不保存属性指标）
  - 保存模板后，三个维度（素材文件夹/设计师/创意人）同步应用相同数据指标
  - 切换维度后，已保存的数据指标模板生效
  - 取消/关闭弹窗，不保存变更

- ### 5.7 指标排序
  - #### 5.7.1 支持排序的指标
    - 安装数、返点后花费、次留、展示、点击、首日充值人数、累计充值人数、首日充值金额、累计充值金额
    - 验证上述指标列头有排序箭头，可升序/降序切换
    - 不在上述列表的指标，验证无排序箭头
  - #### 5.7.2 默认排序
    - 合计粒度：默认按"花费"降序
    - 按日/按双周粒度：默认按"时间"降序
  - #### 5.7.3 排序交互
    - 点击一次列头：升序
    - 再次点击：降序
    - 第三次点击：恢复默认排序
    - 切换维度/粒度后，排序重置为默认

- ### 5.8 导出数据
  - #### 5.8.1 导出触发
    - 点击"导出"按钮，浏览器开始异步下载，页面不跳转
    - 导出文件格式为 .xlsx，验证文件可正常打开
  - #### 5.8.2 文件命名
    - 格式：素材报表_(数据维度)_(年月日时分秒)
    - 示例：素材报表_设计师_20251125160401，验证命名规则
    - 数据维度为当前选中维度（素材文件夹/设计师/创意人）
  - #### 5.8.3 导出内容
    - 包含当前筛选条件下所有分页数据（非仅当前页）
    - 素材文件夹维度：只下载文件夹维度数据，渠道投放详情弹窗数据不下载
    - 导出列与当前自定义指标列一致
  - #### 5.8.4 数据量限制
    - 数据 ≤ 10000 条：正常下载
    - 数据 > 10000 条：弹出提示"数据量超出当前下载上限（10000条），请缩小筛选范围后重新尝试下载"，不触发下载
    - 边界值：恰好 10000 条，验证可正常下载
  - #### 5.8.5 下载状态反馈
    - 下载成功：页面顶部显示轻量通知栏，状态"完成"
    - 下载失败：通知栏显示"下载失败"
    - 通知栏自动消失时间验证

## 六、渠道范围验证

- ### 6.1 已支持渠道
  - B站（P0）：验证素材 MD5 匹配及报表数据
  - 巨量引擎（P1）：验证素材 MD5 匹配及报表数据
  - 腾讯3.0（P1）：图片 MD5 取 source_signature（为空取 signature），验证字段优先级
  - 微博（P1）：验证素材 MD5 匹配及报表数据
  - 百度搜索（P1）：验证从渠道后台拉取转化数据（不走 UData）
- ### 6.2 不支持渠道
  - TapTap：验证报表中不展示该渠道数据，无相关筛选项

## 七、异常场景

- ### 7.1 数据为空
  - 筛选条件下无任何数据，报表显示"暂无数据"提示
  - 空数据时导出，文件仅含表头无数据行
- ### 7.2 网络异常
  - 查询时接口超时，显示错误提示，提供重试入口
  - 导出时接口超时，通知栏显示"下载失败"
- ### 7.3 数据更新边界
  - 当天 9:00 前查询昨日数据，验证是否已更新
  - 查询当前整点前1小时数据，验证是否已包含（每小时更新上一整点）
- ### 7.4 权限控制
  - 无权限用户访问素材报表页面，验证是否提示无权限
  - 部分渠道无授权的用户，验证只展示已授权渠道的数据

  - 表格滚动、列固定、拖拽列宽在各浏览器表现一致
- ### 8.2 屏幕分辨率
  - 1920×1080：报表列不溢出
  - 1280×720：横向滚动正常，固定列正常
