# 全局页面定位功能实现报告

## 🎯 需求背景

用户反馈每次刷新页面都会回到"项目管理"首页，希望：
- **记住最后访问的页面**：无论当前在哪个页面（项目管理/目录管理/Memory/对话等）
- **刷新后恢复**：按F5刷新后自动回到之前的页面，而不是总是回到首页

---

## ✅ 实现方案

### 技术选型

使用 **localStorage** 持久化存储当前页面状态：
- Key: `app_current_tab`
- Value: 当前页面的tab标识（projects/folders/memory/chat/results/casegen/conflicts/settings）

### 核心逻辑

#### 1. 初始化时恢复页面

```jsx
const [tab, setTab] = useState(() => {
  try {
    const saved = localStorage.getItem('app_current_tab');
    const validTabs = ['projects', 'folders', 'memory', 'chat', 'results', 'casegen', 'conflicts', 'settings'];
    if (saved && validTabs.includes(saved)) {
      return saved; // 恢复保存的页面
    }
  } catch (e) {
    console.error('[App] Failed to restore tab:', e);
  }
  return 'projects'; // 默认首页
});
```

**特点**：
- 使用懒初始化函数，只在组件首次挂载时执行一次
- 验证保存的值是否有效，防止恶意篡改
- 如果localStorage中没有或值无效，默认返回'projects'

---

#### 2. 切换页面时保存

```jsx
useEffect(() => {
  try {
    localStorage.setItem('app_current_tab', tab);
  } catch (e) {
    console.error('[App] Failed to save tab:', e);
  }
}, [tab]);
```

**触发时机**：
- 用户点击侧边栏切换页面时
- 通过代码调用`setTab()`时
- 每次tab变化都会自动保存到localStorage

## 💡 设计要点

### 1. 数据验证

```jsx
const validTabs = ['projects', 'folders', 'memory', 'chat', 'results', 'casegen', 'conflicts', 'settings'];
if (saved && validTabs.includes(saved)) {
  return saved;
}
```

**原因**：
- 防止localStorage被恶意篡改成无效值
- 确保只渲染有效的页面组件
- 提高安全性

---

### 2. 错误处理

```jsx
try {
  localStorage.setItem('app_current_tab', tab);
} catch (e) {
  console.error('[App] Failed to save tab:', e);
}
```

**原因**：
- 某些浏览器可能禁用localStorage
- 隐私模式下可能抛出异常
- 防止因存储问题导致应用崩溃

---

### 3. 懒初始化

```jsx
const [tab, setTab] = useState(() => {
  // 这个函数只在首次挂载时执行
  const saved = localStorage.getItem('app_current_tab');
  return saved || 'projects';
});
```

**优点**：
- 避免每次渲染都读取localStorage
- 性能更好
- 符合React最佳实践

## 🔍 localStorage数据结构

```javascript
{
  "app_current_tab": "folders",           // 全局当前页面
  "folders_tab": "cases",                 // 目录管理内的标签页
  "folders_scroll_cases": "800",          // 历史用例的滚动位置
  "folders_scroll_xmind": "300"           // 历史XMind的滚动位置
}
```

**层级关系**：
- `app_current_tab` - 应用级别（一级导航）
- `folders_tab` - 页面级别（二级导航，仅Folders页面）
- `folders_scroll_*` - 组件级别（滚动位置）

## 🛠️ 技术细节

### 1. 支持的页面列表

```javascript
const validTabs = [
  'projects',    // 项目管理
  'folders',     // 目录管理
  'memory',      // Memory
  'chat',        // 对话
  'results',     // 结果
  'casegen',     // 用例生成
  'conflicts',   // 冲突检测
  'settings'     // 设置
];
```

**注意**：
- 如果将来添加新页面，需要在这里添加
- 确保与Sidebar中的tab值一致

---

### 2. 与Folders页面定位的配合

两个定位功能互不干扰：

```
应用级别（App.jsx）：
  app_current_tab = "folders"
  
页面级别（Folders.jsx）：
  folders_tab = "cases"
  folders_scroll_cases = "800"
```

**工作流程**：
1. 用户在Folders的"历史用例"标签，滚动到800px
2. 刷新页面
3. App.jsx恢复 → tab = "folders"
4. Folders.jsx恢复 → folders_tab = "cases"
5. Folders.jsx恢复 → 滚动到800px
6. 完美恢复！✅

---

### 3. 性能考虑

**内存占用**：
- 1个key，存储一个字符串（<20字节）
- 可忽略不计

**读写频率**：
- 初始化：1次读
- 每次切换页面：1次写
- 非常低频

**兼容性**：
- 支持所有现代浏览器
- IE8+也支持localStorage

当前实现不影响浏览器的历史记录。

**行为**：
- 点击侧边栏：改变tab，保存到localStorage
- 按F5刷新：从localStorage恢复
