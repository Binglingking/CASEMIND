# 进度持久化功能测试指南

## 测试场景

### 场景1：刷新页面后恢复进度

**步骤：**
1. 启动一个五阶段分析
2. 等待进度开始显示（看到进度条）
3. 按 `F5` 或 `Ctrl+R` 刷新页面
4. 回到"目录管理" → "历史用例"标签

**预期结果：**
- ✅ 进度卡片自动重新显示
- ✅ 显示最新的进度信息
- ✅ 进度条继续更新
- ✅ 状态显示"● 后台运行中"

### 场景2：切换项目后返回

**步骤：**
1. 在项目A启动分析
2. 切换到项目B
3. 等待几秒
4. 切换回项目A

**预期结果：**
- ✅ 进度卡片仍然显示
- ✅ 显示项目A的最新进度
- ✅ 轮询继续工作

### 场景3：关闭标签页后重新打开

**步骤：**
1. 启动分析
2. 关闭浏览器标签页
3. 重新打开应用
4. 导航到"目录管理" → "历史用例"

**预期结果：**
- ✅ 如果分析仍在运行，进度会恢复
- ✅ 如果分析已完成，不会显示进度

### 场景4：暂停后刷新

**步骤：**
1. 启动分析
2. 点击"暂停"按钮
3. 等待状态变为"已暂停"
4. 刷新页面

**预期结果：**
- ✅ 进度卡片显示
- ✅ 状态显示"● 已暂停"
- ✅ 显示"继续"按钮而非"暂停"按钮

### 场景5：完成后刷新

**步骤：**
1. 等待分析完成
2. 刷新页面

**预期结果：**
- ✅ 不显示进度卡片
- ✅ localStorage已清除
- ✅ 显示完成消息

### 场景6：取消后刷新

**步骤：**
1. 启动分析
2. 点击"取消"按钮
3. 确认取消
4. 刷新页面

**预期结果：**
- ✅ 不显示进度卡片
- ✅ localStorage已清除

### 场景7：长时间运行（超过1小时）

**步骤：**
1. 启动一个大数据量分析
2. 等待超过1小时
3. 刷新页面

**预期结果：**
- ✅ 过期的localStorage数据被清除
- ✅ 如果分析仍在运行，会重新查询并显示
- ✅ 如果分析已结束，不显示进度

### 场景8：localStorage禁用

**步骤：**
1. 在浏览器设置中禁用localStorage
2. 启动分析
3. 刷新页面

**预期结果：**
- ✅ 分析仍正常运行
- ✅ 刷新后不显示进度（因为无法保存）
- ✅ 控制台可能有localStorage相关警告

## 检查点

### 前端控制台日志

应该看到以下日志：

```
[LegacyCaseTab] Restoring analysis progress from localStorage
[LegacyCaseTab] analyze clicked {project: "...", llm: {...}}
[LegacyCaseTab] calling api.legacyAnalyze...
[LegacyCaseTab] analyze result: {...}
```

### localStorage内容

在浏览器开发者工具的 Application → Local Storage 中查看：

**键名：** `analysis_progress_<project_name>`

**值示例：**
```json
{
  "analyzing": true,
  "progress": {
    "project": "投放管理平台",
    "status": "running",
    "current_stage": 2,
    "total_stages": 5,
    "stage_name": "信号抽取（LLM）",
    "total_batches": 875,
    "completed_batches": 123,
    "llm_calls": 123,
    "extracted_signals": 456,
    "elapsed_seconds": 245.3,
    "message": "已完成 123/875 总批次",
    "progress_percent": 28.0
  },
  "timestamp": 1715500000000
}
```

### 网络请求

每2秒应该看到一个GET请求：
```
GET /api/legacy/analyze/progress?project=<project_name>
```

## 常见问题

### Q1: 刷新后没有恢复进度？

**检查：**
1. 后端分析是否仍在运行？
2. localStorage是否有数据？
3. 浏览器控制台是否有错误？
4. 是否在无痕模式下？

### Q2: 进度显示但不动？

**检查：**
1. 网络请求是否正常？
2. 后端服务是否运行？
3. 控制台是否有错误？

### Q3: localStorage保存失败？

**检查：**
1. 浏览器是否禁用了localStorage？
2. 存储空间是否已满？
3. 是否在无痕模式？

## 性能测试

### 小数据量（100条用例）
- 预计总时间：2-5分钟
- 刷新多次验证进度恢复

### 中等数据量（1000条用例）
- 预计总时间：20-60分钟
- 可以切换多个项目测试

### 大数据量（5000条用例）
- 预计总时间：2-8小时
- 可以关闭浏览器后重新打开测试

## 边界情况测试

1. **同时运行多个项目的分析** - 每个项目独立保存进度
2. **快速连续刷新** - 不应产生多个轮询定时器
3. **网络断开后恢复** - 应能重新连接并继续显示
4. **后端重启** - 前端应能检测到并清除状态
5. **浏览器崩溃后恢复** - 应从localStorage恢复

## 验收标准

- [x] 刷新页面后进度不丢失
- [x] 切换项目后进度正确显示
- [x] 关闭标签页后重新打开能恢复
- [x] 暂停状态正确保持
- [x] 完成后自动清除状态
- [x] 取消后自动清除状态
- [x] 过期数据自动清理
- [x] localStorage失败不影响分析运行
- [x] 不会产生内存泄漏（定时器正确清理）
- [x] 不会产生多个轮询实例
