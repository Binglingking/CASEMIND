### 🎯 方案3：智能采样策略（中等复杂度）

**原理**：不是所有用例都需要分析，优先选择代表性用例

**实施思路**：
1. 按模块分组，每个模块随机抽样N条用例
2. XMind节点按深度分层抽样
3. 保证覆盖不同stage/priority

**示例代码**（需要新增）：
```python
def smart_sample(batch: NormalizedBatch, max_cases=100, max_leaves=200):
    """智能采样，保持多样性"""
    # 按模块分组
    by_module = {}
    for c in batch.case_units:
        by_module.setdefault(c.module, []).append(c)
    
    # 每个模块均匀采样
    sampled_cases = []
    per_module = max_cases // max(len(by_module), 1)
    for module_cases in by_module.values():
        sampled_cases.extend(module_cases[:per_module])
    
    # XMind按深度分层采样
    by_depth = {}
    for n in batch.xmind_leaves:
        depth = len(n.path)
        by_depth.setdefault(depth, []).append(n)
    
    sampled_leaves = []
    per_depth = max_leaves // max(len(by_depth), 1)
    for depth_nodes in by_depth.values():
        sampled_leaves.extend(depth_nodes[:per_depth])
    
    return NormalizedBatch(
        project=batch.project,
        case_units=sampled_cases,
        xmind_leaves=sampled_leaves,
        xmind_mid_nodes=batch.xmind_mid_nodes,
    )
```

**预期效果**：
- 用例：从364降至100（减少73%）
- XMind：从649降至200（减少69%）
- **预计费用：5.7 × 0.30 ≈ 1.7美元**（节省70%）

**风险**：
- 可能遗漏某些隐性规则
- 需要仔细设计采样策略

### 🎯 方案5：缓存与增量分析（长期优化）

**原理**：只对新增/变更的用例进行分析

**实施思路**：
1. 为每个用例计算hash指纹
2. 记录已分析的用例ID列表
3. 下次只分析新增或用例内容有变化的

**伪代码**：
```python
def incremental_extract(project, batch, cfg):
    """增量分析，跳过已处理的用例"""
    analyzed_ids = load_analyzed_ids(project)  # 从文件加载
    
    new_cases = [c for c in batch.case_units if c.case_id not in analyzed_ids]
    new_leaves = [n for n in batch.xmind_leaves if n.node_id not in analyzed_ids]
    
    if not new_cases and not new_leaves:
        return [], 0, []  # 无需分析
    
    # 只分析新增部分
    signals, calls, errors = extract(
        NormalizedBatch(
            project=project,
            case_units=new_cases,
            xmind_leaves=new_leaves,
        ),
        cfg=cfg
    )
    
    # 更新已分析列表
    save_analyzed_ids(project, analyzed_ids | {c.case_id for c in new_cases})
    
    return signals, calls, errors
```

**预期效果**：
- 首次：正常费用
- 后续：**仅分析新增部分**（通常<10%）
- **长期平均：节省80-90%**

   - 人工抽检几个候选的准确性

3. **渐进式调整**：不要一次性应用所有优化
