## 使用方法

### 方法1：使用增大批次（自动生效）

无需任何操作，批次大小已自动优化。下次运行五阶段分析时会自动使用新配置。

### 方法2：使用省费模式

1. 进入「文件夹」页面
2. 找到"运行五阶段分析"按钮
3. 勾选旁边的 **"跳过LLM（省费模式）"** 复选框
4. 点击"运行五阶段分析"
5. 确认对话框会提示"不会产生API费用"

**注意**: 省费模式下不会生成新的反哺候选，只会更新风格画像。

## 注意事项

1. **Token限制监控**
   - 增大批次后，单次prompt可能接近模型token上限
   - 如遇超限错误，可适当调小批次大小
   - 建议监控实际token使用量

2. **质量验证**
   - 优化后应验证反哺候选质量是否受影响
   - 对比优化前后生成的InferredKnowledgePoint数量
   - 人工抽检几个候选的准确性

3. **渐进式调整**
   - 当前已实施方案1和2，效果显著
   - 建议先观察一段时间
   - 如需进一步优化再考虑方案3和4

4. **回滚方案**
   - 如需回滚批次大小，修改 `stage2_extract.py` 即可
   - 保留原始配置注释，方便恢复
