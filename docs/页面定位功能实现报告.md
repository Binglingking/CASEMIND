# 页面定位功能实现报告

## 🎯 需求背景

用户反馈每次刷新页面都会跳回首页（"需求文档"标签），希望：
1. **记住标签页**：刷新后保持当前选中的标签页
2. **记住滚动位置**：切换标签或刷新后恢复之前的滚动位置

---

## ✅ 实现方案

### 技术选型

使用 **localStorage** 持久化存储用户状态：
- 标签页状态：`folders_tab`
- 滚动位置：`folders_scroll_{tab}`（每个标签页独立保存）

### 核心逻辑

#### 1. 标签页状态持久化

**初始化时恢复**：
```jsx
const [tab, setTab] = useState(() => {
  try {
    const saved = localStorage.getItem('folders_tab');
    if (saved && ['docs', 'cases', 'xmind'].includes(saved)) {
      return saved; // 恢复保存的标签页
    }
  } catch (e) {
    console.error('[Folders] Failed to restore tab:', e);
  }
  return 'docs'; // 默认值
});
```

**切换时保存**：
```jsx
useEffect(() => {
  try {
    localStorage.setItem('folders_tab', tab);
  } catch (e) {
    console.error('[Folders] Failed to save tab:', e);
  }
}, [tab]);
```

---

#### 2. 滚动位置持久化

**组件挂载时恢复**：
```jsx
useEffect(() => {
  const scrollKey = `folders_scroll_${tab}`;
  
  // 从localStorage读取保存的滚动位置
  const savedScroll = localStorage.getItem(scrollKey);
  if (savedScroll) {
    setTimeout(() => {
      window.scrollTo(0, parseInt(savedScroll, 10));
    }, 100); // 延迟100ms，等待DOM渲染完成
  }
  
  // ...
}, [tab]);
```

**组件卸载时保存**：
```jsx
useEffect(() => {
  const scrollKey = `folders_scroll_${tab}`;
  
  // ...
  
  // 返回清理函数，在组件卸载或tab变化时执行
  return () => {
    try {
      localStorage.setItem(scrollKey, String(window.scrollY));
    } catch (e) {
      console.error('[Folders] Failed to save scroll:', e);
    }
  };
}, [tab]);
```

## 💡 设计要点

### 1. 独立的滚动位置

每个标签页有独立的滚动位置key：
- `folders_scroll_docs` - 需求文档
- `folders_scroll_cases` - 历史用例
- `folders_scroll_xmind` - 历史XMind

**优点**：
- 切换标签时互不干扰
- 每个标签页都能记住自己的位置

### 2. 延迟恢复滚动

使用`setTimeout(..., 100)`延迟执行：

**原因**：
- React组件挂载后需要时间渲染DOM
- 立即执行`scrollTo`可能因为DOM未就绪而失败
- 100ms是一个合理的平衡点（既不太慢，也足够DOM渲染）

### 3. 错误处理

所有localStorage操作都包裹在try-catch中：

**原因**：
- 某些浏览器可能禁用localStorage
- 隐私模式下可能抛出异常
- 防止因存储问题导致页面崩溃

### 4. 数据验证

恢复标签页时验证有效性：
```jsx
if (saved && ['docs', 'cases', 'xmind'].includes(saved)) {
  return saved;
}
```

**原因**：
- 防止localStorage被恶意篡改
- 确保只接受有效的标签值

## 🛠️ 技术细节

### 1. useState懒初始化

```jsx
const [tab, setTab] = useState(() => {
  // 这个函数只在组件首次挂载时执行一次
  const saved = localStorage.getItem('folders_tab');
  return saved || 'docs';
});
```

**优点**：
- 避免每次渲染都读取localStorage
- 性能更好

### 2. useEffect依赖项

```jsx
useEffect(() => {
  // ...
}, [tab]);  // 只在tab变化时执行
```

**作用**：
- 切换标签时自动保存/恢复滚动位置
- 避免不必要的副作用

### 3. cleanup函数

```jsx
return () => {
  localStorage.setItem(scrollKey, String(window.scrollY));
};
```

**执行时机**：
- 组件卸载时（切换到其他路由）
- 依赖项变化时（切换标签页）

## 📈 性能考虑

### 内存占用
- 每个项目最多3个key（每个标签一个）
- 每个key存储一个数字字符串（<10字节）
- 总占用：<100字节/项目

### 读写频率
- 标签切换：1次读 + 1次写
- 页面刷新：1次读（初始化）+ 1次读（滚动恢复）
- 非常低频，不影响性能

### 兼容性
- localStorage支持所有现代浏览器
- IE8+也支持
- 无兼容性问题
